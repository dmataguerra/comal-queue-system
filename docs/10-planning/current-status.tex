\section{Status and planning}
\subsection{Current baseline}

Package version is 1.0.0, the first stable delivery (tag v1.0.0, prepared 4 November 2026); candidate 0.4.1 was folded into it. Current architecture is local Electron/React with JSON persistence, validated IPC and HTTP/SSE loopback. The help center with task search, informational tours and the bundled manual PDF is part of this baseline.

After the release commit, branch qa/automated-regression-suite added QA tooling without changing product behavior: a local Docker TestLink stack, Selenium UI automation, a 46-scenario catalog, the qa:integration, qa:ui and qa:regression commands and one additional HTTP content test. The final regression of 8 November 2026 recorded 37 PASS, 0 FAIL and 9 BLOCKED cases that need physical hardware or a person.

Implemented functionality and available tests are documented separately from their executed results. Dated September, October and November reports remain evidence of their own runs. Publication still requires an approved signing identity and operational acceptance: when this status was written no signed 1.0.0 installer had been published, and a documentation update does not publish a release.
