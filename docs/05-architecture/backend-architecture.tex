\subsection{Queue application and composition}

backend/queue-store.ts is the sole queue-state owner, with injected storage/capacity/date ports. nucleo/turnos.ts contains pure state transitions. main/store.ts binds JSON persistence and composition-specific ports. main/main.ts owns startup and shutdown.

Successful actions save state before notifying subscribers and sending an announcement. On save failure the prior queue, timestamps, undo and announcement sequence are restored. Audio capacity is checked before accepting a call. Expiry uses a single timer and retries failed persistence after five seconds.

This is a single-process local design. It has no distributed queue, service container or database repository.

Evidence: backend/queue-store.ts; main/store.ts
