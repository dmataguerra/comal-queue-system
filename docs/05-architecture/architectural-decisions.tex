\subsection{Implemented architectural decisions}

AD-01: pure queue rules with a single application state owner and injected storage ports. AD-02: preserve installed JSON field names and use atomic writes before broadcasting accepted actions. AD-03: separate operator/public windows with a validated sandboxed preload.

AD-04: optional trusted-local HTTP/SSE transport reuses the same application logic, bound to loopback. AD-05: local prerecorded voice catalog makes normal service independent of synthesis/network availability. AD-06: bounded announcement FIFO with explicit failed/discarded acknowledgements.

AD-07: migrate legacy SQLite read-only without importing historical announcements or retaining old order semantics. AD-08: Windows NSIS installer and signed, evidence-based release gate. These are observations of implementation, not invented original decision rationales.
