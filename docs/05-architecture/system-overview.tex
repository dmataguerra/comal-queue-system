\section{Architecture}
\subsection{System overview}

Comal++ is an Electron application with two React entry points built by Vite. The main process composes queue state, JSON storage, validated IPC, local content, window lifecycle and a loopback HTTP server. No NestJS or Socket.IO server runs in the current product.

Desktop flow: React -> transport -> sandboxed preload -> validated IPC -> queue store -> pure core and JSON storage. Browser flow: React -> browser transport -> HTTP actions and SSE -> the same queue application.

The operator and public display are separate windows. IPC public permissions differ from operator permissions; HTTP is a trusted-local transport and has no per-browser identity.

Evidence: main/main.ts; main/adaptador-ipc.ts; backend/queue-store.ts; shared/contract.ts
