\subsection{Frontend architecture}

vistas/operador/main.tsx and vistas/publica/main.tsx mount separate React 19 pages. Common provider and transport encapsulate Electron/browser differences. Components never import Electron directly for queue operations.

Common modules implement localStorage theme/size, clock, weather, icons, modal and audio controls. The public view handles the announcement FIFO, Web Audio playback, cards, media fallback and uniform display fitting.

Browser transport is provided by public/browser-transport.js. The same-origin browser preferences synchronize between browser views, but not across the desktop custom-protocol origin.

Evidence: vistas/comun/turnero.tsx; vistas/comun/transport.ts; vite.config.ts
