\subsection{Data flow and action boundaries}

LLAMAR -> validate input -> compute pure transition -> check audio capacity -> update latest-call time -> atomic save -> snapshot and optional announcement. Invalid capture returns CAPTURA\_INVALIDA; full audio capacity or failed saving rejects before an accepted state notification.

DESHACER restores one previous snapshot without announcing; QUITAR removes a number and clears undo. Expiry and day change save before publishing. Public renderers report software playback statuses by ID and number.

Media import uses a main-process picker, asynchronous copy into a hidden destination temporary, size verification and exclusive hard-link publication. Existing files are retained with numbered names. Inventory updates reach IPC and SSE subscribers.

Evidence: backend/queue-store.ts; main/contenido.ts; main/entregas-audio.ts
