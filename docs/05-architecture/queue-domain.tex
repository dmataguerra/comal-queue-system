\subsection{Queue domain}

State is actual (number or null), llamados (at most five earlier unique numbers), and one optional undo snapshot. There are no persistent ready/delivered/cancelled records or UUID-based orders in this version.

Input must be one to six decimal digits; normalizar takes the last two. 213298 becomes 98 and 100 becomes 00. Calling current repeats it without reordering; calling an earlier number promotes it and removes its prior occurrence. A new number drops the oldest if six were visible.

Each call refreshes five-minute expiry. Removal and expiry are silent; explicit removal discards undo. Undo cannot restore already expired numbers, and is unavailable after restarting. Day change clears queue state through persisted application logic.
