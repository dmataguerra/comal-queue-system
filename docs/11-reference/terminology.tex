\section{Reference}
\subsection{Terminology and superseded concepts}

Current terms: operador, pantalla pública, actual, llamados, instantanea, anuncio, entregaAudio, config.json and estado.json. HTTP uses SSE; desktop uses IPC. Version 0.3.1 has local JSON persistence and optional loopback browsing.

Legacy 0.2.0 terms such as NestJS, Socket.IO, turns/requests tables, counters, delivered/cancelled records and UUID order identities describe the old product. They apply only to explicit history and migration fixtures, not present operation.

The current visible range includes 00. Default repetition is one, not the historical proposal of two. Six visible recent numbers must not be confused with the separate six-task announcement capacity.
