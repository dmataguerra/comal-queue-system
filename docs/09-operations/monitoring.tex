\subsection{Diagnostics and logs}

Help -> Diagnostics displays app/Electron/Node versions, effective data/config/state/log paths, operator/public status, persistence, last successful save and errors, audio/YouTube health, media counts, visible queue length and free space. The open panel refreshes every ten seconds; individual probe failures return remaining data.

turnero.log stores JSON lines with ISO/local time, level, component, version and session. It rotates at 5 MB with .1 through .5 retained; identical messages within thirty seconds are summarized. Failed logging does not stop the application.

Public renderers report software audio/media health. Browser reports and messages use HTTP and reach the same log. There is no external monitoring service, alerting SLA or automated physical sound detector.

Evidence: main/diagnostico.ts; main/log.ts; vistas/operador/DiagnosticoPanel.tsx
