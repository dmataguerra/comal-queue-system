\subsection{Security and release controls}

Electron windows use sandbox and context isolation; main-frame/sender/page authorization and runtime payload checks guard IPC. Production CSP disallows inline scripts and unsafe-eval, restricts external origins and blocks objects/base URLs. Inline styles remain required for dynamic UI. Window navigation and popup creation are restricted.

Custom protocol and HTTP content resolution enforce allowed roots and reject escaping paths/symlinks. HTTP listens only on loopback and verifies local write headers. There is no LAN access, user identity or confidentiality boundary against a local process with data access.

CI audits high/critical dependency vulnerabilities. CD requires a matching version tag, production environment, both signing secrets and approved COMAL\_SIGNER\_SHA1. It checks valid signatures, exact thumbprint, code-signing use and timestamps on Setup, installed app and uninstaller, and validates the exact artifact hash before release.
