\subsection{Backup, restore and migration}

Close Comal++ and verify its processes are stopped. Run npx tsx scripts/datos.ts backup DATA BACKUPS. The tool creates a unique dated backup of config/state/content and logs, excluding temporaries; the finished name is published only after copy completion.

Restore with npx tsx scripts/datos.ts restore BACKUP DATA --app-cerrada. The flag confirms the operator checked shutdown; it does not reliably detect all app processes. JSON, configuration keys, state dates and overlapping paths are validated before replacement. Prior target data is kept at datos.antes-de-restaurar-*.

Corrupt startup state is copied to estado.json.corrupto-* when possible and starts empty with warning; unreadable state due to I/O errors stops startup. Old-day state never reopens prior turns. A same-day restore uses stored timestamps and does not replay audio.

Migration from 0.2.0 reads legacy SQLite unchanged; migration from Documentos to 0.3.1 copies once and retains the original. Rollback requires the old verified installer and its own pre-upgrade data backup; post-migration calls are not reverse-converted to SQLite.
