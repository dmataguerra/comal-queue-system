\subsubsection*{Persisted application defaults}

If no configuration row exists, multimedia is fallback/stopped at volume 65 and unmuted. Settings use an 8-second visual announcement, automatic page rotation, and three Spanish footer messages. Writes merge partial input into current/default values and store the whole JSON document.

\subsubsection*{Frontend/build configuration}

Vite development uses fixed port 5173 with strict-port behavior and proxies \Code{/api}, \Code{/media}, and \Code{/socket.io}. The production build outputs \Code{dist}. The server serves static content only when \Code{dist/index.html} exists. TypeScript targets ES2022 and strict mode.

Electron packages Windows x64 NSIS, uses per-user installation by default, permits changing installation directory, includes \Code{dist}, \Code{build}, \Code{electron}, package metadata, and copies \Code{data/music} as extra resources.

\subsubsection*{Runtime configuration limits}

Settings are global to the database, not per screen. Media playback progress/audio permission is browser-local. Environment variables are process settings only; there is no \Code{.env} loader, configuration file parser, or UI for server settings.
