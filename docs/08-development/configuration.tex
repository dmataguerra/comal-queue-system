\subsection{Configuration fields}

config.json defaults: youtubeUrl=null; repeticiones=1 (accepted 1 or 2); volumenVoz=1 (0-3); volumenMusica=0.6 (0-1); atenuacionMusica=0.15 (0-1); segundosBanner=8 (integer 3-120); pantallaPublica=null (or integer display ID); recargaDiaria=04:00 (24-hour HH:MM); mensajes contains two default messages.

mensajes accepts at most ten nonblank strings, each at most 160 characters. Invalid or unknown fields are logged and defaulted/ignored. Incomplete JSON during watch keeps the prior config; valid file updates propagate after a 300 ms debounce. Voice above 100\% may distort.

Daily reload time remains a 24-hour configuration field even though both visible clocks use 12 hours with am/pm. Theme and size are localStorage keys comal.tema and comal.tamanio, not config.json fields and not covered by the data backup.

Evidence: main/config.ts; vistas/comun/tema.ts; tamanio.ts
