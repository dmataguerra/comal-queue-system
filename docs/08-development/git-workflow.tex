\subsection{Git workflow and parallel changes}

Use a separate branch and checkout for parallel work; do not switch the branch of a checkout being edited by another session. Coordinate file ownership and inspect the other session's committed changes before merging or publishing documentation.

This documentation branch is codex/documentacion-integral, based on f0d842a from codex/production-readiness. The parallel session owns implementation/tests; this session owns README files, docs and audio-tool documentation. Interface details are reconciled with its final code and evidence.

Review the diff and exact base before opening a PR. A documentation branch based on unmerged implementation must declare that dependency. Do not claim a new installer or passing application run from a documentation-only change.
