\subsection{Coding standards}

Use TypeScript contracts at renderer/main boundaries and runtime validators for untrusted payloads. Keep pure queue transitions in nucleo and side effects behind the queue store ports. Preserve compatibility-sensitive JSON and IPC names.

ESLint covers backend/main/nucleo/shared/vistas/scripts and vite.config.ts. Prettier format and format:check target the same maintained code, workflows and package/config files; Markdown/LaTeX are reviewed separately. .gitattributes and formatting use LF.

Add focused regressions for meaningful behavior changes; use isolated data for destructive tests. Never commit signing keys, API tokens or generated operational data.

Evidence: eslint.config.js; package.json; .gitattributes; .gitignore
