\subsection{Project structure}

main/: Electron lifecycle, adapters, config, persistence, security, content and local server. backend/: queue application and ports. nucleo/: pure rules for turns, FIFO and YouTube URLs. shared/: contracts, channels and announcement limits.

vistas/: separate operator/public React entry points, shared controls and styles. public/: static assets and browser transport. contenido/: factory voices, notice, banners and optional videos. tooling/audio/: generation and verification tools. scripts/: build, packaging, recovery and regression automation.

.github/workflows/: validation, legacy fixture, signed release and endurance. docs/: current Markdown guides, technical LaTeX hierarchy, historical reports and reproducible user PDFs. data/: legacy SQLite artifacts, not active production storage.
