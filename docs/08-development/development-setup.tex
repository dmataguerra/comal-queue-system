\section{Development}
\subsection{Setup}

Use Windows and Node.js >=22.13.0 with npm. Run npm ci from the checkout, then npm run dev. The development script starts Vite at 127.0.0.1:5173 and Electron with TURNERO\_DEV\_URL; it does not start a NestJS process.

For built execution, run npm run build followed by npm start. Use TURNERO\_DATOS to isolate experiments from production or development data. Before review run format:check, lint, npm test and build; then appropriate smoke scripts for the changed behavior.

Evidence: package.json; scripts/dev.mjs; vite.config.ts
