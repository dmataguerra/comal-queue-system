\subsection{Environment variables}

TURNERO\_DATOS: explicit data directory for isolated runs. TURNERO\_PUERTO='0': request an operating-system-selected free loopback port for isolated tests; other values retain the normal default. Browser and full-day smoke scripts request isolated ports; the browser test reads its own instance's logged origin and verifies its data directory. This does not enable LAN binding. TURNERO\_DEV\_URL: development view origin supplied by scripts/dev.mjs; not a production LAN setting. TURNERO\_SMOKE\_QUICK and TURNERO\_MEDIA\_MODE are script-specific test options.

WIN\_CSC\_LINK and WIN\_CSC\_KEY\_PASSWORD: release signing certificate and password; CSC\_LINK/CSC\_KEY\_PASSWORD are supported packager fallbacks. COMAL\_SIGNING\_CERT\_SHA1 selects the local certificate for --firma-local. COMAL\_SIGNER\_SHA1 is the approved signer thumbprint checked by CD, a different variable.

AZURE\_SPEECH\_KEY, AZURE\_SPEECH\_REGION and AZURE\_SPEECH\_ENDPOINT belong only to audio generation; ELEVENLABS\_API\_KEY belongs to its generator. They are unnecessary for playback or restaurant operation. Keep all credentials out of the repo and logs.
