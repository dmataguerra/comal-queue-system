\section{Product and scope}
\subsection{Product vision}

Comal++ announces ready restaurant orders using the last two digits of a manually entered ticket. A Windows PC runs the operator interface and the public display, with local announcement audio and optional multimedia. The system supports unordered kitchen output; it does not generate an order sequence.

Core operation needs neither Internet nor a network service on another machine. YouTube and weather are optional external features. Business acceptance requires the intended PC, extended TV display and speakers.
