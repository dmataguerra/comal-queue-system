\subsection{Implemented scope and boundaries}

Implemented: input of one to six digits, display of the last two (00-99), calling and recalling, one-level correction, removal, five-minute expiry and six recent visible numbers. State is saved locally before an accepted call is announced.

Implemented: separate React operator/public windows, local audio, ducking of multimedia, import/removal of videos and banners, optional desktop YouTube, diagnostics, JSON persistence, backup/restore CLI, and migration from compatible 0.2.0 SQLite data.

The local browser transport uses HTTP and SSE on the same PC. It does not enable LAN access, and does not support YouTube. No login, administrator account, counter assignment, delivered/cancelled order history, sales, POS integration, printing, inventory or payment processing is implemented.

Evidence: shared/contract.ts; backend/queue-store.ts; main/servidor-web.ts
