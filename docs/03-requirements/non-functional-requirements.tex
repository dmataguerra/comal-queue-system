\subsection*{Desired but undefined requirements}

Availability, acceptable state propagation latency, maximum concurrent screens, history retention, backup recovery point/time, supported browsers, minimum display resolution and viewing distance, accessibility conformance, performance budgets, maximum queue length, media-storage capacity, log retention, security threat model, and maintenance response times all \textbf{require stakeholder definition}. No numerical target is asserted.

The previous README requires offline core operation, but public audio activation currently prevents classifying offline audible announcements as satisfied.
