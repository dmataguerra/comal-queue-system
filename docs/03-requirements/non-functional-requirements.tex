\subsection{Non-functional requirements}

NFR-01: normal queue and local media remain functional offline. NFR-02: atomic JSON writes publish only complete files; a save failure rejects the action. NFR-03: renderer isolation, sandbox, CSP and validated IPC enforce desktop capability boundaries. NFR-04: web transport binds only to 127.0.0.1 and validates Host and write Origin.

NFR-05: queue audio is bounded to six announcements, start wait to 45 seconds and task duration to 30 seconds. NFR-06: logs rotate at 5 MB with five previous files. NFR-07: Windows x64 packaging must pass installation, upgrade and rollback validation before release.

No measured physical audio latency, formal SLO or guaranteed power-loss durability of the storage device is asserted.
