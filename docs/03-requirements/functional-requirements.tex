\subsection{Functional requirements}

FR-01: accept one to six decimal digits and announce the last two, including 00; reject invalid input without changing the display. FR-02: maintain one current and at most five called numbers without duplicates. FR-03: recalling reorders a listed number, or repeats current audio without duplicating it.

FR-04: support silent one-level correction and explicit removal. FR-05: expire each number five minutes after its latest call, and reset on day change. FR-06: reject calls when six audio announcements are outstanding, with a warning from five.

FR-07: play notice plus selected local voice, one or two repetitions, with media ducking. FR-08: import supported media asynchronously and report skipped files without overwriting existing content. FR-09: expose diagnostics, Help, volume, theme and size controls. FR-10: backup and restore through the CLI with the app closed.

Evidence: nucleo/turnos.ts; main/contenido.ts; main/respaldo.ts
