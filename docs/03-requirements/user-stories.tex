\subsection{User stories}

US-01: as operator, call a complete ticket quickly while only its last two digits appear publicly. US-02: as operator, repeat or correct a call without duplicated visible numbers. US-03: as operator, receive a compact notice and keep my input when audio is full or persistence fails.

US-04: as customer, see readable current/recent numbers and hear local voice. US-05: as operator, import videos/images and keep a local fallback when desktop YouTube fails. US-06: as support owner, inspect Diagnostics and recover an app-closed backup safely.
