\subsection{Acceptance criteria}

AC-01: 213298 becomes 98; 00 is accepted; seven digits, signs and nonnumeric input leave state unchanged. AC-02: a recall leaves unique numbers in order; repeating current creates another announcement ID. AC-03: removal clears pending correction and pending announcements for that number.

AC-04: six outstanding announcements cause a further call to fail without state/ID/undo mutation. AC-05: failed persistence produces no accepted call or new announcement. AC-06: restore rejects corrupt data without changing the target and preserves previous target data on successful replacement.

AC-07: Help is available in the header and by F1, without a redundant sidebar entry; size offers seven steps from 70\% to 130\%; both clocks show a 12-hour time with am/pm. These interface changes are coordinated with the parallel implementation session.

Hardware acceptance remains separate: verify HDMI, Windows scale, speakers and real connected YouTube if used.
