# Propuestas visuales del README

Se eligió la **primera propuesta**. En la implementación final, solo logos, iconos y bordes utilizan pixel art; todo el texto permanece como Markdown.

Tres conceptos generados con la herramienta de imágenes, con el casco troyano pixel art y capturas del proyecto como referencias:

1. [Azul institucional](01-azul-institucional.png): portada clara con identidad académica.
2. [Terminal troyana](02-terminal-troyana.png): composición oscura con acentos azules.
3. [Campus pixel](03-campus-pixel.png): ilustración de cafetería y comunidad universitaria.

Son bocetos de composición, no capturas del README implementado ni evidencia de funcionamiento. Las miniaturas representan la interfaz; los avatares son ilustrativos, no retratos ni una lista real de colaboradores. La implementación utiliza texto Markdown y enlaces reales.

Especificación de generación: README en español para Comal++, FIF y UAQ; secciones de proyecto, tecnologías, instalación, documentación, contribuciones y contacto; demostración de operador y pantalla pública; casco existente como referencia de identidad. En la revisión final se pidió convertir todos los elementos decorativos —iconos, marcos, insignias y avatares— al pixel art de contornos escalonados y colores sólidos del casco, conservando las pantallas de la aplicación sin pixelar. Se corrigieron los requisitos a Windows x64 y Node.js 22.13.0 o posterior y se evitó atribuir ventas o pagos al sistema.
