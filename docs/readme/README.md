# Recursos del README

El diseño sigue la propuesta **01, azul institucional**. Títulos, descripciones, tablas y comandos son texto Markdown. Solo casco, iconos y bordes decorativos utilizan pixel art.

## Capturas y demostración

Los archivos `media/operador.png` y `media/publica.png` son capturas de las ventanas reales de la aplicación compilada, identificada como versión 0.4.1, con datos de demostración aislados. Se realizaron llamadas a los números 98, 07 y 56.

`media/comal-dos-pantallas.mp4` y su vista previa GIF combinan capturas sucesivas de ambas ventanas: operador a la izquierda y público a la derecha. No incluyen audio y no representan una prueba de hardware HDMI. Los 96 fotogramas se presentan a cuatro fotogramas por segundo; el tiempo de captura depende del renderizado y no constituye una medición de rendimiento. `media/dos-pantallas.png` conserva el último fotograma compuesto.

El casco `media/trojano.png` se extrajo del icono existente de la aplicación, sin redibujarlo. Los iconos SVG provienen de `public/assets/icons/pixel/`, con color azul; el separador es geometría SVG sin texto.

Las [tres propuestas](propuestas/README.md) son bocetos generados con imágenes. Su texto rasterizado y colaboradores ilustrativos no forman parte del README definitivo.

## Iconos de tecnologías

Los iconos de Electron, React, TypeScript, Vite, Tailwind CSS, Node.js y GitHub Actions proceden de [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons). Se descargaron los SVG `original` de cada tecnología y se adaptaron a una cuadrícula de 32 × 32 con colores sólidos y bordes escalonados. Se conservan localmente para evitar depender de un servidor de imágenes al consultar el README.

Estas adaptaciones se distribuyen con la [licencia MIT original de Devicon](media/tecnologias/LICENSE.txt). Las marcas pertenecen a sus respectivos titulares; su uso identifica las tecnologías empleadas y no implica patrocinio.
