\subsection{Configuration and support interface}

There is no administrator account or separate administration page. Multimedia import/removal, YouTube and volumes are operator capabilities. Diagnostics is a support panel accessed through Help and refreshed every ten seconds while open.

Additional config.json fields can be edited locally; watch-based validation keeps the previous configuration while JSON is incomplete. For backup/restore or manual file repair, close the app first and use the effective path shown in Diagnostics.

Evidence: main/config.ts; vistas/operador/DiagnosticoPanel.tsx; docs/operacion-recuperacion.md
