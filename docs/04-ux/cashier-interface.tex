\subsection{Operator interface}

Turnos accepts one to six ticket digits; Enter calls the last two. A successful call clears capture. Invalid input, audio saturation or a failed save must not be mistaken for a new call. Each visible row offers Anunciar and Quitar with confirmation; the operator can omit those confirmations for the current session.

Corregir última captura restores one previous call silently. Ctrl+Z edits the input text, not queue history. Persistent warnings are grouped in a compact expandable notice; row statuses identify En espera, Anunciando, Anunciado, Falló el audio and discarded announcements. Short feedback does not replace Diagnostics.

Help is in the header and F1, without sidebar duplication. There are no counters, delivered-state workflow or order-history screen.
