\section{Cashier interface}

\subsection*{Purpose and main user}

The cashier workspace supports day-to-day ready-list operation and display configuration. Its main user is the queue operator; because authorization is absent, this is a UX role rather than a security identity.

\subsection*{Components and actions}

\begin{itemize}
  \item \textbf{Sidebar/top bar:} choose Turns, Multimedia, or Settings; open the public display; view local connection state; toggle automatic turn-page rotation.
  \item \textbf{New ready turn:} enter 1--2 digits, select optional counter 1 or 2, and submit. Successful creation clears/refocuses the number input.
  \item \textbf{Repeat panel:} select an active turn and explicitly reannounce it.
  \item \textbf{Ready list:} newest/recalled first, with an action dialog per turn. The dialog can save a changed counter, mark delivered, or enter a second confirmation step before cancellation.
  \item \textbf{Multimedia:} configure YouTube or local playlists, refresh the catalog, pause/resume, mute/unmute, change volume, or return to fallback visuals.
  \item \textbf{Settings:} set announcement duration and footer lines, test local announcement audio in the cashier browser context, and open the public display.
\end{itemize}

\subsection*{State and dependencies}

The page reads snapshots and connection status from \Code{SystemProvider}, then writes through \Code{src/services/api.ts}. All mutation controls associated with queue/media state are intended to be disabled while disconnected. Feedback is shown in an inline live region on the Turns section and a toast elsewhere.

\subsection*{UX constraints and discrepancies}

\begin{itemize}
  \item The interface does not search or filter a long ready list.
  \item The announcement-duration input advertises maximum 20 seconds, while server validation permits 30.
  \item The audio test activates only the cashier tab's Web Audio context; it does not activate public-screen audio.
  \item Media/settings controls are effectively administrative but share the operator interface and authorization level.
  \item The responsive layout changes from full sidebar to rail to horizontal navigation at defined CSS breakpoints.
\end{itemize}
