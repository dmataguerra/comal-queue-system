\section{User experience}
\subsection{Interface overview}

The operator workspace has Turnos and Multimedia navigation, a header with Help, voice/media volume, seven size levels (70-130\%) and Azul/Morado theme. Diagnostics is accessed at the end of Help. F1 opens Help and Escape closes it.

Both views use a 12-hour clock with am/pm. The theme selector reserves width to avoid a layout shift. The coordinated wave background uses subtle continuous motion over 24-31.8 seconds, with 33 sinusoidal geometry samples per cycle; reduced-motion preferences are respected.

Theme and size are stored in localStorage and propagated by storage events to same-origin views. Desktop and HTTP browser storage are different origins: their preferences do not automatically synchronize with each other.

Evidence: vistas/comun/tema.ts; tamanio.ts; hooks/useClock.ts; vistas/operador/OperadorPage.tsx
