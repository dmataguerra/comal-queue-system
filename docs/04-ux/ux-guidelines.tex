\subsection{Interaction and accessibility guidance}

Preserve fast keyboard capture, focus return after Help and semantic labels on icon controls. Keep warnings concise, expandable and attached to their consequence; never label failed software audio as announced. Do not hide save failures behind success feedback.

Use the intended TV at viewing distance to assess legibility. Preserve reduced-motion behavior for backgrounds. The existence of focus styles, labels and reduced-motion CSS does not establish an accessibility certification or screen-reader acceptance.

Historical screenshots of the 0.2.0 interface are not authoritative; use the current screenshot inventory.
