\subsection{Public display}

The public display presents one current number and up to five earlier numbers, large announcement cards, multimedia and a footer. It does not paginate an unbounded list. Numbers expire five minutes after their latest call.

DisplayCanvas fits and centers a 1920x1080 composition uniformly in available CSS pixels. Different aspect ratios leave black margins. This fit scale is separate from the 70-130\% size preference. A secondary Windows display gets fullscreen; without one the public view is a normal window on the primary display.

Technical diagnostics and operator capture do not appear publicly. Software audio acknowledgements do not prove that customers heard the speakers.
