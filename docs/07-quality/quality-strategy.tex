\section{Quality and verification}
\subsection{Quality strategy}

Separate code evidence, executed automated checks, historical reports and target-hardware acceptance. A test script or old PASS does not certify a newly built installer. Retain exact commit, artifact SHA-256, environment and results for each delivery.

Validate pure rules and persistence in unit tests, then transport/audio/UI in Electron smoke tests, then the exact installer and upgrade fixture. The 390-minute endurance run and physical sound/display checks are separate acceptance requirements.
