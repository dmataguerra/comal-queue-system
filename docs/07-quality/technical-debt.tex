\subsection{Technical debt and evidence gaps}

Open acceptance work includes the real restaurant PC/TV/audio, connected desktop YouTube and weather, final signer trust/timestamp and a completed 390-minute report on the release candidate. Resource distribution rights require owner review.

There is no single-output coordinator for multiple public audio clients, no per-browser authentication and no cross-origin synchronization of theme/size. These are design limits, not commitments to implement new features.

Historical source references, screenshots and PDF text have been refreshed in this documentation branch. Future behavior changes must update the sources and regenerate PDFs, with visual review and explicit test evidence.
