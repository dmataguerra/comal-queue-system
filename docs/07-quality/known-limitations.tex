\subsection{Known limitations}

Normal operation is one Windows x64 PC; remote/LAN devices are unsupported. Browser YouTube is disabled. Desktop YouTube, weather and embedded-content availability need real Internet acceptance. There is no authenticated administrator or persistent order history.

Six visible recent numbers are not an order ledger; a seventh distinct call displaces the oldest and each number expires after five minutes. Six outstanding audio tasks may temporarily prevent further calling. Restart does not recover undo or replay old announcements.

Playback acknowledgements prove software execution, not physical audio. Multiple public windows can duplicate sound. There is no synchronized media timeline between windows. Theme/size preferences are origin-local and outside the JSON backup.

Public release requires approved signing identity and hardware/endurance acceptance; documentation alone does not satisfy those gates.
