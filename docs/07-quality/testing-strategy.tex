\subsection{Test commands and scope}

npm test validates the audio catalog and nucleo/main/lifecycle tests. npm run lint and npm run format:check validate maintained code/config. npm run build type-checks and compiles both renderer and main entry points.

test:desktop covers windows and local playback; test:browser covers HTTP/SSE, browser audio reports and logs; test:hardening covers announcement identity/capacity and asynchronous import; test:media covers local media. test:interface and test:theme cover controls, help, preferences and UI synchronization. test:destructive covers destructive regressions in isolated data.

test:recovery runs the actual backup/restore CLI and stores hashes/results. test:installed needs an already built installer. test:upgrade needs a verified 0.2.0 fixture. test:full-day:preflight is a short startup check; test:full-day runs 390 real minutes. Its updated preflight checks eight confirmed announcements, saturation rejection without mutation, invalid input, correction and reload without replay. The full run drains outstanding audio before corrections/reloads, checks TV/memory/file agreement, bounds capacity retries to 120 seconds and exercises recovery halfway through the real run. A preflight PASS does not establish a full-run PASS. Manual display-scale, background and audio-control smoke scripts remain available.
