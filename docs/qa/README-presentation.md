# Presentación QA

Archivo generado: `Comal Queue System Quality Assurance.pptx`.

Para regenerarlo desde la raíz del repositorio:

```powershell
py -3 docs\qa\generate_presentation.py
```

El script usa únicamente texto de los artefactos QA versionados y capturas
locales del manual en `docs\user-manual\source\screenshots\0.4.0\`. No ejecuta
pruebas ni modifica código productivo.
