Las imágenes separadas y su procedencia están en [el inventario de 0.4.0](source/screenshots/0.4.0/inventario.json). El [estado del manual](README.md) distingue esta edición de los PDF de texto.

| Estado           | Debe verse                                                            |
| ---------------- | --------------------------------------------------------------------- |
| Turnos           | Captura, En pantalla, Anunciar, Quitar y Corregir última captura.     |
| Llamada aceptada | Número actual y acuse En espera/Anunciado.                            |

| Confirmación     | Anunciar/Quitar y opción para omitir durante la sesión.               |

| Multimedia       | Importación, tarjetas, YouTube desktop y motivos de rechazo.          |
| Ayuda            | Encabezado/F1, sin Ayuda en sidebar, enlace a Diagnósticos.           |
| Preferencias     | Siete tamaños 70–130%, Azul/Morado y relojes am/pm.                   |

Usar números ficticios y ocultar rutas de usuario. Registrar commit, fecha, transporte, resolución y escala. La pantalla pública sí reproduce audio; una captura no acredita sonido físico.

Las capturas actuales están en `source/screenshots/0.4.0/`, con nombres descriptivos como `turnos.png`, `acciones-turno.png`, `publica-anuncio.png`, `volumen.png`, `multimedia.png`, `youtube.png` y `diagnosticos.png`. El inventario distingue recursos recuperados de nuevas capturas. Para reemplazar una imagen, conservar su función y actualizar procedencia, dimensiones y hash. No renombrar las ocho imágenes históricas como si fueran nuevas.

Para futuras ampliaciones conviene capturar la franja de saturación con el ticket rechazado conservado, el diálogo completo de confirmación y Ayuda. No se presentan como imágenes disponibles en esta edición.
