\subsection{HTTP routes and request requirements}

GET / redirects to /vistas/operador/index.html; GET /publica redirects to /vistas/publica/index.html. GET /api/inicial returns Inicial with browser content URLs. GET /api/diagnostico returns local diagnostics. GET /api/events streams JSON event envelopes.

POST /api/accion accepts LLAMAR, DESHACER or QUITAR. POST /api/volumen accepts [voz, multimedia]. POST /api/youtube accepts null only; a URL is rejected in browser mode. POST /api/salud accepts [tipo, estado]. POST /api/registro accepts a bounded string. POST /api/audio accepts [id, n, estado].

POST /api/contenido/importar accepts videos or banner and opens a native picker on the PC. POST /api/contenido/quitar accepts an inventory URL beginning /contenido/. POST /api/contenido/abrir accepts a category or null and opens the local folder.

GET /contenido/... and built static assets resolve only within allowed roots, supporting single byte ranges. POST requires Origin equal to the actual loopback origin, Content-Type exactly application/json, and X-Turnero-Cliente exactly navegador. Host must match actual bind address and port; query strings/hashes and unsupported methods are rejected. Body text length is bounded to 65536.

Evidence: main/servidor-web.ts; main/seguridad-ipc.ts
