\subsection{Data contracts and compatibility}

Accion = \{tipo: LLAMAR, entrada: string\} | \{tipo: DESHACER\} | \{tipo: QUITAR, n: number\}. Instantanea = \{actual, llamados, puedeDeshacer, optional persistencia/advertenciaRecuperacion\}. ResultadoDespacho = \{instantanea, efecto: ANUNCIAR/CAPTURA\_INVALIDA/null, anuncio\}.

Anuncio = \{id: number, n: number, optional limiteInicio\}. EntregaAudio = \{id, n, estado, fecha, optional motivo\}; estado is pendiente, reproduciendo, reproducido, fallo or descartado. IDs are local to the running session and are not durable order UUIDs.

Inicial contains instantanea, config, inventario, pantallas and optional delivery state/history. Inventario contains videos/banner URL arrays, 100 voice slots, notice URL and optional revisionAudio. Pantallas.publica is tv, ventana or ninguna. Result import reports agregados, omitidos, cancelado and optional motivos.

Config keys and persisted JSON are compatibility-sensitive. See the configuration section for defaults/ranges; do not replace them with legacy SQLite settings contracts.
