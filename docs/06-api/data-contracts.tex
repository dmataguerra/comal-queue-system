\section{Data contracts}

All timestamps emitted by the server are ISO 8601 strings created by \Code{new Date().toISOString()}.

\subsection*{Turn}
\begin{verbatim}
{
  id: string,                  // UUID
  number: string,              // "01" through "99"
  counter: 0 | 1 | 2,
  status: "ready" | "delivered" | "cancelled",
  createdAt: string,           // ISO date-time
  readyAt: string,             // ISO date-time
  lastAnnouncedAt: string,     // ISO date-time
  rank: number                 // positive monotonic integer
}
\end{verbatim}

\subsection*{Announcement}
\begin{verbatim}
{
  id: string, turnId: string, number: string,
  counter: 0 | 1 | 2, createdAt: string
}
\end{verbatim}

\subsection*{Multimedia and settings}
\begin{verbatim}
Multimedia = {
  type: "fallback" | "youtube" | "local",
  url: string | null,
  playlistId: string | null,
  playing: boolean, volume: number, muted: boolean
}

Settings = {
  announcementSeconds: number,
  autoRotate: boolean,
  footerMessages: string[]
}
\end{verbatim}

Server defaults are fallback media, stopped, volume 65, unmuted; announcement duration 8 seconds; automatic rotation enabled; and three Spanish footer messages.

\subsection*{Playlist catalog}
\begin{verbatim}
Track = { id: string, title: string, url: string }
Playlist = { id: string, name: string, cover: string, tracks: Track[] }
AppState = { turns: Turn[], multimedia: Multimedia,
             playlists: Playlist[], settings: Settings }
\end{verbatim}

\subsection*{Contract debt}

\Code{src/types.ts} incorrectly declares turn/announcement timestamps as numbers and makes \Code{Settings.autoRotate} optional, while server contracts use ISO strings and require the field in snapshots. Client and server models are duplicated. No schema generation or runtime response validation exists.
