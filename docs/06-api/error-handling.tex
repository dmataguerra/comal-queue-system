\subsection{Error semantics}

Invalid capture is a successful dispatch result with CAPTURA\_INVALIDA and no mutation. Full announcement capacity and failed saving reject the call; the operator preserves its ticket for retry. The interface removes the Electron remote-method wrapper from human-facing errors and uses brief queue-full feedback.

HTTP validation/operation failures normally return 400 with \{error: message\}. Host or write-header mismatch returns 403. Unsupported routes/query/method combinations return 404 or 405 according to route handling. Invalid media range returns 416. After a streamed response starts, a later error destroys the response instead of returning another JSON document.

These status codes are implementation behavior, not a REST error schema promising separate 409/422/503 domain codes.
