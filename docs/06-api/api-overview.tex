\section{API and contracts}
\subsection{API overview}

The primary desktop API is window.turnero, typed as TurneroApi in shared/contract.ts. It exposes initial state, validated actions, subscriptions, volume/YouTube configuration, content management, diagnostics, logging and playback reports.

The optional HTTP interface is an internal same-PC transport at http://127.0.0.1:4317. Its routes are listed below. There is no versioned public API, NestJS controller, Socket.IO endpoint, turn-history resource or promise of external client compatibility.

TURNERO\_PUERTO='0' requests a free local port for isolated tests; the actual origin is logged. With the normal default, if 4317 is busy, failure is logged and desktop windows remain usable. Browser transport needs the running app and built views.

Evidence: shared/contract.ts; main/servidor-web.ts
