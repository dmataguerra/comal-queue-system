\subsection{Daily operating journey}

Before service: verify Windows extended display and output device, open Help from the header or F1, then Diagnostics; test a ticket and listen on the actual speakers. During service: call ready orders, monitor the compact notices and per-number audio status, and use repeat/remove only as appropriate.

After service: close the application before backing up the effective data directory. After recovery or upgrade: verify version, queue, content, sound and display before serving customers. Previous-day state and old announcements do not replay automatically.
