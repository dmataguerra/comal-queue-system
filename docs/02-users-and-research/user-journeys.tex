\section{User journeys}

\subsection*{Ready-to-pickup journey}

\begin{verbatim}
Preparation outside COMAL Queue
        |
Operator enters existing ticket and optional counter
        |
Server validates + stores READY turn + request record
        |
Socket.IO state and announcement events
        |
Public display shows turn and visual announcement
        |
Customer presents ticket and collects order
        |
Operator marks DELIVERED; turn leaves active display
\end{verbatim}

\subsection*{Capture-error journey}

\begin{verbatim}
READY turn selected in cashier list
        |
Operator chooses "Retirar por error de captura"
        |
Confirmation dialog
        |
PATCH status=CANCELLED
        |
Turn remains in history but leaves active display
\end{verbatim}

\subsection*{Recall journey}

\begin{verbatim}
Operator selects READY turn -> POST announce
 -> rank and last-announced time change
 -> new ephemeral announcement emitted
 -> turn becomes first in ready order
\end{verbatim}

\subsection*{Local-media journey}

\begin{verbatim}
Maintainer copies supported audio into data/music/<genre>
 -> operator refreshes catalog
 -> server resolves and allow-lists files
 -> operator selects playlist
 -> public client requests /media/<genre>/<filename>
 -> tracks advance on ended events
\end{verbatim}

The intended audio step in the pickup journey is not included as achieved behavior: assets and playback code exist, but the public screen cannot set \Code{audioEnabled} to true.
