\section{Users and research}
\subsection{User groups}

The operator enters tickets, repeats or removes numbers and manages multimedia on the local PC. The customer observes the public display without editing queue state. The installation/support owner configures Windows, audio, data backups and release acceptance.

These are operating responsibilities, not authenticated accounts. Desktop IPC restricts public-window capabilities, but the loopback HTTP API trusts local access. No separate administrative identity exists.
