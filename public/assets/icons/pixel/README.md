# Comal pixel icons

21 original SVG assets supplied in `comal-pixel-icons.zip`.
The artwork uses a 24 × 24 grid with transparent backgrounds and crisp edges.

The shared `Icon` component renders these assets as CSS masks so they inherit
the color of each control in both themes. Existing icon dimensions are preserved.
Names without a supplied pixel version continue to use the Phosphor collection.
The pixel chevron already points right and needs no rotation in the breadcrumb.
