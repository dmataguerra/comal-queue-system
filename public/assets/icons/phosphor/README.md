# Phosphor Duotone

Source: https://github.com/phosphor-icons/core (assets/duotone), retrieved 2026-09-25.
License: MIT; see LICENSE. SVG artwork is unmodified; filenames map to the application icon names. Rendered as CSS masks to inherit the active theme.

Current integration: `vistas/comun/components/Icon.tsx` uses pixel assets where available and this collection as fallback. Artwork is masked to inherit Azul/Morado control colors; this attribution remains applicable to the distributed SVG files.
